VPN
Step 1: Open Server Manager
Click Manage

Select Add Roles and Features
(The Add Roles and Features Wizard will open.)

Step 2: Start Installation
Click Next on Before You Begin

Choose Role-based or feature-based installation

Select your server from the list

In Server Roles, select Remote Access

Click Next on Features

Step 3: Add VPN Role
In the Remote Access role services window, select:

DirectAccess and VPN (RAS)

Click Next

Accept default options and click Install

Wait for installation to complete.

Step 4: Configure Routing and Remote Access
Go to Tools → Routing and Remote Access in the Server Manager

Right-click your server name and select Configure and Enable Routing and Remote Access

A wizard opens. Click Next.

Step 5: Choose Configuration Type
Select Custom Configuration, then click Next

Check the boxes for:

VPN access

(Optionally) NAT if server connects to the internet

Click Next, then Finish

When prompted, Start the service.

Step 6: Assign IP Address Range for Clients
Right-click your server name → Properties

Go to the IPv4 tab

Choose Static address pool and click Add

Add a range of IPs for VPN clients (e.g. 192.168.20.1 to 192.168.20.50)

Click OK

Step 7: Configure Authentication
Go to the Security tab

Ensure Authentication provider is set to Windows Authentication

Click OK

Step 8: Enable User Access
Open Computer Management → Local Users and Groups → Users

Right-click the user → Properties → Dial-in tab

Select Allow access

Click OK

Step 9: Allow VPN Through Firewall
Open Windows Firewall → Advanced Settings

In Inbound Rules, enable:

Routing and Remote Access (PPTP-In)

Routing and Remote Access (L2TP-In)

Save and exit

Step 10: Verify VPN Functionality
From a client system, open the Network Connections panel

Create a new VPN connection pointing to the VPN server’s public IP or DNS name

Enter credentials of a user allowed VPN access

Click Connect

If connected successfully, test internal resource access (e.g. ping internal IP).

(Optional) Step 11: Configure NAT for Internet Sharing
In Routing and Remote Access, expand IPv4 → NAT

Right-click and select New Interface

Choose the external network connection → select Public interface connected to Internet

Enable NAT on this interface

Add internal interface if necessary

Step 12: Restart and Verify Service
Right-click your server name in Routing and Remote Access

Click Restart

Confirm VPN clients can connect and browse internal/external resources securely.

NPS
Step 1: Open Server Manager
Click Manage → Add Roles and Features
(The Roles and Features Wizard will open.)

Step 2: Install the NPS Role
Click Next on Before You Begin

Choose Role-based or feature-based installation

Select your Server

Under Server Roles, check Network Policy and Access Services

Click Next

On Role Services, select Network Policy Server

Click Next → Install

Wait for installation to complete.

Step 3: Open NPS Console
Go to Tools → Network Policy Server in the Server Manager

The NPS management console opens

Step 4: Register Server in Active Directory
Right-click NPS (Local)

Select Register server in Active Directory

Confirm when prompted

This allows NPS to read users’ dial-in properties from Active Directory

Step 5: Configure RADIUS Clients
In the left panel, expand RADIUS Clients and Servers → RADIUS Clients

Right-click and select New

Enter:

Friendly name: e.g. VPNServer01

Address (IP or DNS): IP of the VPN or wireless device

Shared Secret: define a common key for secure communication

Click OK

Step 6: Create Network Policies
Expand Policies → Network Policies

Right-click and select New

Enter Policy Name e.g. VPN Access Policy

Choose Type of network access server → Remote Access Server (VPN-Dial-Up)

Add Conditions, such as:

Windows Groups: Domain Users

NAS Port Type: Virtual (VPN)

Under Constraints, select authentication methods (e.g., MS-CHAPv2, PEAP)

Under Settings → IP Filters, leave default or apply restrictions

Click Finish

Step 7: Configure Connection Request Policies (Optional)
Expand Policies → Connection Request Policies

Right-click and select New

Define name and specify Condition based on NAS IP or FQDN

Under Processing, specify whether NPS handles requests locally or forwards them to another RADIUS server

Step 8: Verify Settings and Start Service
Verify that NPS (Local) shows status Running

If not, right-click and choose Start NPS Service

Confirm RADIUS service is listening on ports 1812 (Authentication) and 1813 (Accounting)

Step 9: Configure Firewall
Open Windows Defender Firewall → Advanced Settings

Enable inbound rules for Network Policy Server (RADIUS Authentication - (UDP-In) 1812) and Accounting - (UDP-In) 1813

Step 10: Test the Connection
Connect a remote VPN or wireless client that uses NPS for authentication

Verify that authentication succeeds and log entries appear under
Event Viewer → Custom Views → Server Roles → Network Policy and Access Services

Step 11: Monitor NPS Activity
Expand Accounting → Log File Properties

Ensure log file creation and format (date/time) are correct

Check connection attempts, grant/deny events, and session history
