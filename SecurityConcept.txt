6.tcpdump
-----------------------------------------------------------------------------------------------------------------------------------------------------------
1. Download link of pcap file: https://malware-traffic-analysis.net/2024/11/26/index.html

We’ll analyze the file 2024-11-26-traffic-analysis-exercise.pcap, which contains traffic from a host infected with NetSupport RAT, a known remote access Trojan.

------------------------------------------------------------------------------------------------------------------------------------------------------------

2.To view the contents of a PCAP file with TCPdump, navigate to where the file was downloaded and unzipped and use the -r option to read the file:
	
#sudo tcpdump -r 2024-11-26-traffic-analysis-exercise.pcap

------------------------------------------------------------------------------------------------------------------------------------------------------------

3.get the total packet count 

#sudo tcpdump -r 2024-11-26-traffic-analysis-exercise.pcap –count

26922 packets total

------------------------------------------------------------------------------------------------------------------------------------------------------------

4.to read in human readble language 

#tcpdump -tttt -r 2024-11-26-traffic-analysis-exercise.pcap

----------------------------------------------------------------------------------------------------------------------------------------------------------

5.Add Source IP Filtering: Based on the alerts we can surmise that 10.11.26.183 is the infected host. Filter packets where this IP and 194.180.191.64 is involved and check the count of packets.

#tcpdump -r 2024-11-26-traffic-analysis-exercise.pcap host 10.11.26.183 and host 194.180.191.64 -tttt –count

this will give 132 filtered packets 

----------------------------------------------------------------------------------------------------------------------------------------------------------

6. Add the -n flag to prevent the TCPdump from resolving IP addresses to hostnames, speeding up the capture and keeping the output in raw IP format..
		

#tcpdump -n -r 2024-11-26-traffic-analysis-exercise.pcap host 10.11.26.183 and host 194.180.191.64 -tttt


we confirm the traffic between 10.11.26.183 and 194[.]180[.]191[.]64.

----------------------------------------------------------------------------------------------------------------------------------------------------------

7.NetSupport service is known to be widely abused and used in NetSupportRAT.and we can see netsupport manager/gateway etc on screen 

#tcpdump -n -A -tttt -r 2024-11-26-traffic-analysis-exercise.pcap host 10.11.26.183 and host 194.180.191.64

---------------------------------------------------------------------------------------------------------------------------------------------------------

8.Search for Specific HTTP Requests: Use grep to find GET and POST requests, which may indicate interactions with web resources. Be sure to use the -A flag to filter for ASCII characters.

#tcpdump -n -A -r 2024-11-26-traffic-analysis-exercise.pcap host 10.11.26.183 and host 194.180.191.64 -tttt | grep -E "GET|POST"

-----------------------------------------------------------------------------------------------------------------------------------------------------------
